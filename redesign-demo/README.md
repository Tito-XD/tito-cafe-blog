# 重构 demo：菜单式首页

暂存的重构方向，还没有接进站点，也不参与构建和部署。

直接用浏览器打开 `index.html` 即可，三个文件要放在同一目录：

- `index.html`：首页、文章列表（`#/blog`）、文章页（`#/posts/<slug>`），含开灯 / 关灯
- `logo.svg`：`src/icons/logo.svg` 的副本
- `tito.webp`：`src/assets/tito_xd-cafe-manager-by-frankuwu.png` 裁边缩小后的版本

## 想法

- 首页就是一张菜单：店长在左，右边一页列完最近文章、Touls、友链和关于
- 点线连到“价格”：文章是“读完大约几分钟”，工具是类别
- 颜色取自立绘：围裙做文字，衬衫蓝做链接，皮背带棕只做点缀；深色模式的底色是围裙
- 字体用霞鹜文楷，小字说明用系统字体
- 文章按年分组，标签筛选代替分页

## 还是假的地方

- 文章数据手抄自 `src/content/posts` 的 frontmatter，只有《独自一人的周六午后》放了正文
- “读完大约”按正文字数每分钟 400 字粗估，图片链接也计入，偏高
- 标签做了精简，筛选上的数字不是站点真实计数
- 霞鹜文楷从 jsDelivr 加载，正式做需要自托管
- 只在无头 Chrome 的 1280 和 390 宽度下看过，没上真机
